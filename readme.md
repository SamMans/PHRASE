## Overview

PHRASE addresses the challenge of real-time gait phase recognition from wearable IMU sensors. Unlike pure deep learning approaches that require extensive training data, PHRASE integrates:

| Component | Role |
|-----------|------|
| **Heuristic Detectors** | Rule-based identification of gait events (peaks, zero-crossings) |
| **Prior Knowledge** | Gaussian distribution models of biomechanical patterns |
| **Bayesian Inference** | Probabilistic combination of heuristic detections and prior models |
| **Post-Heuristics** | Refined transition timing for clinical accuracy |
| **ANN Classifier** | Time-domain feature-based phase recognition |

### Key Features

- ✅ **Real-time inference** - Sample-by-sample processing without look-ahead
- ✅ **Multi-activity support** - Walking, ramp ascent/descent, stair ascent/descent
- ✅ **Multi-modal fusion** - Accelerometer + gyroscope from bilateral shanks
- ✅ **Patient-level cross-validation** - Robust evaluation on unseen subjects
- ✅ **Benchmark comparisons** - 6 deep learning architectures included

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/PHRASE.git
cd PHRASE
```

### 2. Set Up Python Environment

Create and activate the Conda environment with all dependencies:

```bash
conda env create -f tf_env.yml
conda activate tf
```

The `tf_env.yml` includes:
- `tensorflow==2.10`
- `numpy`, `scipy`, `pandas`
- `matplotlib`, `seaborn`
- `scikit-learn`, `statsmodels`
- `pingouin`, `tqdm`

### 3. Verify MATLAB Path

Ensure MATLAB can access the `training/` directory. Add it to your MATLAB path if needed:

```matlab
addpath(genpath('/path/to/PHRASE/training'))
```

## Dataset Format

### CSV File Requirements

Each CSV file must contain the following columns:

| Column | Description |
|--------|-------------|
| `Right_Shank_Ax`, `Right_Shank_Az`, `Right_Shank_Gy` | Right shank sensors (Ax, Az: accelerometer; Gy: gyroscope) |
| `Left_Shank_Ax`, `Left_Shank_Az`, `Left_Shank_Gy` | Left shank sensors |
| `Mode` | Activity mode (`1` = walking, other values for ramps/stairs) |
| `phase` | Gait phase label (0-6 for walking; see table below) |

### File Naming Convention

```
AB{subject_code}_circuit{trial_number}.csv
```

Example: `AB001_circuit01.csv`

- Subject code: characters 3-5 (e.g., `001`)
- Trial number: after `circuit`

### Gait Phase Codes (Walking)

| Code | Phase | Abbreviation |
|------|-------|--------------|
| 0 | Loading Response | LR |
| 1 | Mid-Swing | MST |
| 2 | Terminal Swing | TS |
| 3 | Pre-Swing | PSW |
| 4 | Initial Swing | ISW |
| 5 | Mid-Swing | MSW |
| 6 | Terminal Swing | TSW |

### Metadata File (`metadata.json`)

```json
{
    "signal_parameters": {
        "sampling_frequency": 250
    },
    "gait_phases": {
        "phase_names": ["LR", "MST", "TS", "PSW", "ISW", "MSW", "TSW"]
    }
}
```

## Training PHRASE (MATLAB)

### Quick Start

```matlab
% Navigate to training directory
cd /path/to/PHRASE/training

% Run training for a single subject
PHRASE_Train("BLISS_training", "001", "W", 10);

% Or run k-fold cross-validation for all subjects
trainAll
```

### Training Options

| Parameter | Description | Example |
|-----------|-------------|---------|
| `ds` | Dataset folder name | `"BLISS_training"` |
| `unseen_code` | Subject to use as test | `"001"` |
| `activity` | Activity type | `"W"` (walking), `"RA"`, `"RD"`, `"SA"`, `"SD"` |
| `seq_sz` | Sequence size (for benchmark compatibility) | `10` |

### Training Outputs

| Output | Location | Description |
|--------|----------|-------------|
| Prior accuracy per phase | MATLAB console | Heuristic + Bayesian performance |
| ANN confusion matrices | Figures | Training, validation, test |
| Model JSON | `../checkpoints/phrase_model_*.json` | Trained parameters |

## Inference & Benchmarking (Python)

### Activate Environment

```bash
conda activate tf
cd /path/to/PHRASE/benchmarking
```

### Train Benchmark Models

```bash
# Train LSTM model
python train.py --path ../resources/BLISS_training --model lstm --ratio 1

# Train CNN-LSTM
python train.py --path ../resources/BLISS_training --model cnn-lstm --ratio 1

# Train Transformer
python train.py --path ../resources/BLISS_training --model transformer --ratio 1
```

**Arguments:**
| Argument | Description |
|----------|-------------|
| `--path` | Path to training dataset |
| `--model` | Model type (`lstm`, `cnn-lstm`, `convGRU`, `gnn`, `transformer`) |
| `--ratio` | Sampling rate ratio (1 = same rate as training) |

### Run Inference

```bash
# Evaluate a trained model on test subjects
python inf.py --dataset BLISS_inference --pretrained ../checkpoints --model lstm --eval test
```

**Arguments:**
| Argument | Description |
|----------|-------------|
| `--dataset` | Inference dataset name (in `resources/`) |
| `--pretrained` | Path to checkpoints directory |
| `--model` | Model type |
| `--abl` | Ablation mode for PHRASE (`full`, `ANN`, `HANN`) |
| `--eval` | Evaluation type (`train`, `valid`, `test`) |

### Statistical Analysis

```bash
# Compare PHRASE against all benchmarks
python analysis.py --ds1 BLISS_inference --metric accuracy
```

**Outputs:**
- Paired Wilcoxon test results with effect sizes
- 95% confidence intervals (bootstrap)
- Per-class precision, recall, F1, specificity

## Model Architectures

| Model | Description | Input Shape |
|-------|-------------|-------------|
| **PHRASE** | Hybrid heuristic-Bayesian-ANN | Window × 6 sensors |
| **LSTM** | Standard LSTM sequence classifier | Sequence × (Window × 6) |
| **CNN-LSTM** | CNN feature extractor + LSTM | Sequence × Sensors × Window × 1 |
| **ConvGRU** | Convolutional GRU (Shi et al.) | Sequence × 1 × Window × Sensors |
| **ST-GCN** | Spatial-Temporal Graph Conv Net | Sequence × Window × 6 sensors |
| **Transformer** | Vanilla Transformer encoder | Sequence × (Window × 6) |

## Evaluation Metrics

The framework computes the following metrics:

| Metric | Description |
|--------|-------------|
| **Accuracy** | Overall classification accuracy |
| **Precision** | Positive predictive value per class |
| **Recall (Sensitivity)** | True positive rate per class |
| **Specificity** | True negative rate per class |
| **F1 Score** | Harmonic mean of precision and recall |
| **Inference Time** | Average processing time per window |
| **Transition Delay** | Timing error between predicted and true phase transitions |

### Statistical Testing

- **Paired Wilcoxon signed-rank test** for non-parametric comparison
- **Rank-biserial correlation (RBC)** as effect size
- **Common Language Effect Size (CLES)**
- **Bootstrap 95% confidence intervals** (percentile method)

## Reproducing Results

### Complete Workflow

1. **Prepare dataset** - Place CSV files in `resources/BLISS_training/` and `resources/BLISS_inference/`

2. **Train PHRASE** (MATLAB):
   ```matlab
   cd training
   trainAll   % Trains on all subjects, saves models to ../checkpoints/
   ```

3. **Train benchmarks** (Python):
   ```bash
   cd ../benchmarking
   python train.py --path ../resources/BLISS_training --model lstm --ratio 1
   python train.py --path ../resources/BLISS_training --model transformer --ratio 1
   # ... repeat for other models
   ```

4. **Run inference**:
   ```bash
   python inf.py --dataset BLISS_inference --model lstm --eval test
   python inf.py --dataset BLISS_inference --model phrase --abl full --eval test
   ```

5. **Statistical analysis**:
   ```bash
   python analysis.py --ds1 BLISS_inference --metric accuracy
   ```

6. **Results** - JSON files with per-subject metrics saved in each dataset directory

## Troubleshooting

| Issue | Solution |
|-------|----------|
| MATLAB cannot find CSV files | Ensure the dataset path is correct and files follow naming convention |
| Python cannot find `tensorflow` | Activate conda environment: `conda activate tf` |
| Out of memory during training | Reduce batch size or sequence length |
| CUDA errors | Install compatible CUDA version (11.8 for TensorFlow 2.10) |
| `findpeaks` warnings in MATLAB | Normal behavior; can be suppressed with `warning('off')` |
